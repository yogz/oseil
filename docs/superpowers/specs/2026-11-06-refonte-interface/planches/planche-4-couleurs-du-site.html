Planche 4 — les couleurs des carrés du site actuel

Les six couleurs exactes des cent carrés du site actuel, posées sur la maquette Quant. Le site les décline en deux versions : une vive (affichée quand le téléphone est en mode clair) et une plus profonde (affichée en mode sombre). Les deux sont ici sur le fond noir de Quant.

Clique sur « Je prends celle-ci » sous celle que tu avais en tête, puis dis-moi dans le terminal.
